# Project 1 IronHack

A fork of [EloK6/Merman](https://github.com/EloK6/Merman). It's a browser project made for Ironhack (Project 1), with a merman theme.

## What's inside

- `index.html` and `merman.html`: the pages.
- `script.js`: the page logic.
- `css/`, `fonts/` and `images/`: styles and assets.

## How to view it

Open `index.html` in a browser, or see the upstream live page at https://elok6.github.io/Merman/.
